# Voice Assistant

## Description

This is a Python-based Voice Assistant project that can perform various voice-controlled tasks using speech recognition and text-to-speech technologies.

The assistant can:

* Open websites
* Search Google
* Answer general questions using Wikipedia
* Provide weather updates
* Set reminders
* Open system applications
* Tell current date and time

## Features

* Speech Recognition
* Text-to-Speech Response
* Google Search
* Wikipedia Integration
* Weather Updates using OpenWeather API
* Reminder System
* Open YouTube, Google, GitHub
* Open Calculator, Notepad, VS Code
* Greeting System
* Error Handling

## Technologies Used

* Python
* pyttsx3
* SpeechRecognition
* Wikipedia API
* OpenWeather API
* Requests

## Installation

Install required libraries:

pip install -r requirements.txt

## API Key Setup

This project uses the OpenWeather API.

Steps:

1. Create an account on OpenWeatherMap
2. Generate your API key
3. Replace:

API_KEY = "your_api_key"

with your own API key in the Python file.

## How to Run

Run the Python file:

python main.py
