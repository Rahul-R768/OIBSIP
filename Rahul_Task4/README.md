# Weather App

## Description

This project is a GUI-based Weather Application developed using Python and Tkinter.
The application fetches real-time weather information using the OpenWeather API.

Users can enter a city name and get:

* Temperature
* Humidity
* Weather condition
* Weather icons/emojis

The application also supports:

* Celsius and Fahrenheit conversion
* Error handling
* Input validation

---

## Features

* Real-time weather updates
* GUI interface using Tkinter
* Weather API integration
* Temperature unit conversion
* Humidity display
* Weather condition display
* Weather emojis/icons
* Invalid input handling
* Internet connection error handling

---

## Technologies Used

* Python
* Tkinter
* Requests Library
* OpenWeather API

---

## API Setup

1. Create a free account on OpenWeather.
2. Generate your API key.
3. Replace this line in the code:

API_KEY = "your_api_key"

with your actual API key.

---

## How to Run

Run the Python file:

python main.py

---

## Output

The application displays:

* City name
* Temperature
* Humidity
* Weather condition with icons
